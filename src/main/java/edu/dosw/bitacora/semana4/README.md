## Preguntas Finales
- ¿Qué entendía mal antes?

Antes no entendia como hacer un diagrama de contexto adecuadamente
al igual que no entendia a que hace referencia las flechas en el sistema.
Ademas no sabia hacer un documento de analisis de requerimientos, no pensaba que 
fuera tan largo.

- ¿Qué entiendo ahora?

Entiendo como hacer mejor un documento de analisis de requerimientos, sabiendo como definir
entradas y salidas en el sistema, los flujos y el mockup que son necesarios para 
comprender adecuadamente a la hora de programar

- ¿Qué me falta reforzar?

Entender mejor como graficar un diagrama de contexto teniendo en cuenta
mas actores y mas informacion relacionada, al igual que con los diagramas de caso de uso.
